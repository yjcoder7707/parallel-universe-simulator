# 🌌 Parallel Universe Simulator

A Python-based project that simulates multiple parallel universes using Object-Oriented Programming (OOP).

In this simulator, the same character can exist in different universes with different professions, abilities, and identities.

The project is developed using basic Python and demonstrates the four fundamental pillars of Object-Oriented Programming.

## 🚀 Features

- Create and manage multiple parallel universes.
- Create alternate versions of the same character.
- Assign different professions and abilities to characters.
- Manage character energy levels.
- Execute different events in different universes.
- Demonstrate real-world applications of OOP concepts.

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming
- Python ABC Module (Abstraction)

## 🧠 OOP Concepts Implemented

This project demonstrates:

1. **Encapsulation** – Protecting character energy data.
2. **Inheritance** – Creating specialized characters from a parent class.
3. **Polymorphism** – Implementing different abilities using the same method name.
4. **Abstraction** – Defining abstract universe events.

Additional concepts:
- Classes and Objects
- Constructors
- Method Overriding
- Composition
- `super()` Function
